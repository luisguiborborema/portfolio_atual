## 2. Requisitos Técnicos e de Design
- **Tecnologias:** HTML5 semântico, CSS3 (com variáveis CSS e um design system estruturado) e JavaScript puro (Vanilla).
- **Estética:** O design deve ser premium. Utilize tendências modernas como glassmorphism, um dark mode elegante, gradientes sutis e tipografia limpa (ex: Inter, Roboto ou Outfit).
- **Interatividade:** Implemente animações suaves, efeitos de hover (micro-interações) e revelação de elementos ao rolar a página (scroll reveals). O site deve parecer vivo.
- **Responsividade:** O site deve ser perfeito tanto no desktop quanto no mobile.

## 3. Estrutura do Site
1. **Hero Section:** Uma apresentação impactante com meu nome, cargo e botões para o LinkedIn, Instagram e "Ver Projetos".
2. **Projetos:** Uma grade (grid/cards) elegante exibindo meus cases de sucesso.
3. **Contato:** Rodapé ou seção final com uma chamada para ação clara.
