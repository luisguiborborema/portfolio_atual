1. Tecnologias: HTML, CSS (Vanilla) e JavaScript.
2. Design System: Utilize variáveis CSS para cores, espaçamentos e tipografia. Não utilize frameworks como Tailwind ou Bootstrap.
3. Estética Premium: Aplique paletas de cores sofisticadas (ex: dark mode elegante com acentos vibrantes), glassmorphism, sombras suaves e gradientes de bom gosto.
4. Tipografia: Use fontes modernas do Google Fonts (ex: Inter, Outfit ou Roboto).
5. Animações: O site deve parecer vivo. Inclua micro-interações nos botões e cards, além de animações de revelação (scroll-reveal) nas seções.
6. Responsividade: Mobile-first ou adaptação fluida para qualquer tamanho de tela.
</requisitos_tecnicos_e_design>
